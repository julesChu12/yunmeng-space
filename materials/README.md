# 把素材放在这里

一套房子一个文件夹，可以直接放图片、PDF、图纸、视频、文字或原始压缩包。不用先挑出封面，也不用先整理成网站格式。

推荐结构（有多少放多少，没有的可以留空）：

```text
materials/
  客餐厅项目A/
    项目说明.txt
    实景/
    效果图/
    图纸/
    过程照片/
    视频/
```

`项目说明.txt` 可以照着填写：

```text
对外项目名：可以暂空，由我们一起起名
城市：可只到城市，不需要详细住址
面积、户型：不知道可以不填
项目状态：概念 / 设计中 / 已落地
Gina实际负责：柜体设计、软装搭配、量房、出图、选材、下单核对等
业主需求：最初想解决什么
设计考虑：做了哪些选择，为什么
保留家具：哪些东西沿用了
板材、饰面、五金：只写确定的信息，不需要凑品牌
图片类型：哪些是效果图，哪些是实景，哪些是参考图
公开范围：哪些图可以公开，哪些需要遮挡
补充：可直接粘贴聊天中的需求和设计说明
```

把文件放好后，告诉我文件夹位置，以及要不要替换现有概念提案。我会先阅读、归类，再做选图、图片优化、文案与批注配置，更新页面后给你预览。

不要把参考图当作自己的项目。真实案例写清实际设计职责；涉及索菲亚、爱格等品牌时，只陈述项目中真实使用的产品或合作关系。

`materials/` 不会复制到网站发布目录。只有你决定展示、并整理进 `public/images/` 的素材会成为网站资源。整个压缩包不会直接公开。

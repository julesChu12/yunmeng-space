# 云梦空间

云梦空间品牌站，展示Gina的居家设计与品牌社媒入口。沿用已选定的浅灰绿、居家图片与设计师手记方向。Web 与手机 H5 共用一套响应式页面。

拟用公司名：**北京云梦空间装修设计有限公司**。目前仅保存在配置中，不将其展示为已登记的公司主体。

## 启动

需要 Node.js 22 或以上。没有第三方运行依赖，不需要 `npm install`。

```bash
cd "/Users/yt/projects/forme/website"
npm run dev
```

打开终端打印的地址，默认 `http://127.0.0.1:4173`。源码或内容修改后会重新生成，刷新浏览器查看。服务器只监听本机。

```bash
npm run check   # 构建并检查内容、图片与本地链接
npm run test:dev # 在隔离副本验证模板更新会反映到预览页面
npm run build   # 生成 dist/ 静态网站
npm run preview
```

`PORT=其他端口 npm run dev` 可以换端口。源码不依赖任何托管平台，首次只做本地预览，未进行外部发布或 Git 操作。

## 页面与交互

- 首页：设计师介绍、文字引线批注、设计提案筛选、服务范围、合作流程、手记与常见问题。手机端隐藏图内批注，通过图下文字切换说明。
- `/projects/`：提案列表。案例和手记有各自独立、可分享的静态网址。
- 案例详情：设计考虑、项目事实、图片与大图查看。
- `/journal/`：设计手记列表与文章详情。
- 需求窗口：生成、复制、下载文字清单，不上传或自动发送。正式微信号及二维码尚未提供，窗口明确提示联系方式整理中。
- 手机菜单、原生弹窗焦点管理、键盘关闭、减少动态偏好及自动深色模式。

## 素材如何交给我

**推荐：一套房子一个文件夹，直接放到 `materials/`，再告诉我位置。**

文件夹或压缩包都可以。见 [素材说明](materials/README.md)。我会按真实项目归类，选择封面和细节图、优化图片、编写说明，再更新网站。不需要你先把所有照片整理成最终格式。

原始素材不参与构建，也不会因为放进这个目录就公开。当前没有后台管理、图片上传服务、数据库、访客信息收集或埋点。

## 自己修改内容

| 文件 | 管理内容 |
| --- | --- |
| `content/site.json` | 名称、设计师介绍、首页文案、批注、服务、FAQ、联系方式 |
| `content/projects.json` | 案例、封面、分类、图集、设计过程 |
| `content/notes.json` | 手记列表与文章正文 |
| `public/images/` | 最终展示的图片 |
| `src/styles.css` | 颜色、字号、间距、响应式布局 |
| `src/templates.mjs` | 页面结构 |
| `src/client.js` | 筛选、批注、需求清单和图片大图 |

### 替换一个概念提案

1. 把最终图片放在 `public/images/项目英文名/`，建议使用英文短文件名。
2. 编辑 `content/projects.json` 中对应记录。保留 `slug` 可保持旧网址不变。
3. 替换 `title`、`summary`、`cover`、`coverAlt`、`facts`、`sections` 和 `gallery`。
4. 确认是真实项目后，把 `kind` 从 `concept` 改为 `real`，并准确更新 `imageCredit`。使用效果图时仍需标注“效果图”，不得写成实景。
5. `categories` 控制筛选，`featured` 控制是否出现在首页，`published` 控制本次构建是否生成该记录。
6. 运行 `npm run check`，刷新页面查看。

新增案例时复制一条记录并更换唯一 `slug`，例如 `beijing-living-room`。`sections` 是标题与文字组成的数组，`gallery` 是图片数组。构建会检查路径与必填字段。

**注意：当前构建覆盖生成同路径页面，不主动删除旧文件。** 删除案例、变更 `slug` 或将已生成记录改为不发布时，应使用新的空输出目录构建发布包，并确保线上旧网址按需删除或重定向；仅隐藏列表不能收回已经公开的图片。

### 更换首页图片和设计批注

`content/site.json` 中的 `hero.image` 是首页大图。批注在 `hero.notes`：

```json
{
  "id": "storage",
  "label": "柜体收纳",
  "x": 79,
  "y": 30,
  "title": "柜子怎么做，先看里面放什么。",
  "text": "写清楚这处设计考虑了什么。"
}
```

`x`、`y` 是图片显示区域中的百分比坐标。换图后需同时校对手机与电脑的批注位置，不能直接沿用旧坐标。

### 补上微信和社交账号

编辑 `site.json` 的 `contact`。空字段不展示，不会生成虚假联系方式。

```json
{
  "wechat": "你的真实微信号",
  "qrImage": "/images/contact/wechat.png",
  "phone": "",
  "xiaohongshuUrl": "",
  "douyinUrl": "",
  "bilibiliUrl": "",
  "weiboUrl": ""
}
```

微信号／二维码填写后会出现在需求窗口，并启用页脚的微信咨询入口。手机号选填。社交链接填完整的 `https://` 账号主页地址，支持平台提供的 HTTPS 分享短链接；不要填写平台首页来代替自己的账号。

所有页面的底部共用品牌社媒区，显示平台图标与名称。小红书、抖音、哔哩哔哩、微博和微信均预留入口，尚未配置时显示“筹备中”，没有虚假跳转；填写后启用对应入口。外部主页在新窗口打开，并设置安全隔离。这里填写的联系方式会公开给所有访问者。

社媒图标使用本地内嵌的 Simple Icons 16.0.0 品牌图形，不依赖外部 CDN 或新增运行依赖。来源与项目许可记录在 `src/socials.mjs`；抖音使用其与 TikTok 共用的音符图形，平台名称和跳转配置仍为“抖音”。

## 上线前

### GitHub Pages 公开预览

仓库内的 `.github/workflows/pages.yml` 在推送到 `main` 后自动检查并发布 `dist/`。在 GitHub 仓库的 Settings → Pages 中选择 GitHub Actions 作为发布来源。现代版网址是 `https://<账号>.github.io/<仓库>/modern/`，原居家版位于同一站点根目录。

构建会使用 Pages 提供的子目录前缀，同时处理页面链接、图片、响应式封面、放大图片和 JSON 中的视频资源路径。手动验证可运行 `DEPLOY_BASE_PATH=/yunmeng-space npm run check` 及 `npm run test:deploy`。普通 `npm run dev` 仍使用根路径。

预览继续保持 `noindex,nofollow`，不填写正式域名和已登记公司主体。分享链接是公开访问入口；`noindex` 只表示请求搜索引擎不收录，不限制别人打开。仓库仅包含网站源码、公开内容和展示素材，原始交付目录 `materials/`、本机环境文件及验收截图已忽略。

第一版是可运行的网站草稿，尚未接入真实案例、微信、域名或备案信息。页面默认 `noindex,nofollow`，`robots.txt` 禁止抓取，以免概念内容被当成正式作品收录。

正式上线时，先核对所有公开内容，再填写 `siteUrl` 为真实完整域名、`indexable: true`，构建后才会生成有效的 canonical、分享图地址和站点地图。上线所需的备案与平台配置按实际托管位置处理。公司已登记且名称确认后，再设置 `companyRegistered: true` 并填写实际全称。

## 实现边界

### 现代影像版预览与替换

新增入口 `/modern/`，原居家版仍在 `/`。现代版采用静音循环视频首屏、客餐厅与厨房切换、空间筛选、详情弹窗和设计思路切换；咨询与社媒配置复用原站，不需要后台。

内容与资源路径集中在 `content/modern.json`，文件放在 `public/media/modern/`：

- `scenes`：每个场景的 `desktop`、`mobile` 是电脑和手机视频，`poster`、`mobilePoster` 是对应静态封面。使用 H.264 MP4，静音、短片循环，并启用 faststart。当前每个电脑片约 1 MB，手机版约 0.35 MB。
- `spaces`：展示图、标题、分类、说明与详情中的 `considerations`。`position` 控制图片裁切重心。
- `details`：收纳、材质、搭配的说明和图片。
- `sources`：来源、作者和许可记录。每个视频及空间提案通过 `sourceId` 对应来源。

当前视频来自 Mixkit Free License 条目 3090、43033；照片来自 Pexels，具体原页与许可见 `/modern/sources/`。均作为公开素材示意，没有写成自有案例。替换真实项目时同时更新文字、来源与素材提示，区分实景和效果图。你可以直接把素材按项目放进目录，并注明空间类型、想保留的画面与项目事实，再由我挑选、压缩、裁切并更新配置。

首屏在自动播放受限或视频出错时保留封面；减少动态效果或节省流量模式下默认静态，可手动播放。离开首屏或切到后台会暂停。预览服务支持 MP4 的 Range 请求，验收命令为 `npm run check`、`npm run test:dev`、`npm run test:media`。

采用静态生成，把内容、页面结构和交互分开：修改案例不需要改模板；无需为早期展示站维护数据库、登录系统或后台，符合当前的 KISS / YAGNI。页面与页脚等公共结构统一复用，避免重复修改。服务端仅用于本地预览。
